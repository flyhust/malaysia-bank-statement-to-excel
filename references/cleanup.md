# Description and Counterparty cleanup

The bank prints one run-together string, e.g.

```
DUITNOW TRSF CR 000000ACME TRADING SDN. BHD.INV 123 REF-45 20251208RHBBMYKL010OCB...
```

## Description = what the account holder typed

- Remove: the transaction type (`DUITNOW TRSF CR`, `TSFR FUND DR-ATM/EFT`, `IBG CREDIT`, `DuitNow/Instant Trf`), the bank's running/serial number, and the trailing bank stamp of date + bank code (`20251208RHBBMYKL010OCB…`, `…PBBEMYKL…`).
- Keep whatever the customer wrote, however casual: `FUND TRANSFER`, `BALANCE`, `WORKER CLAIM`, typos. Do not fix, translate or polish.
- Description says what the money was for. The name is already in Counterparty; don't repeat it. If the customer re-typed the payee's name in their note, keep only the reference part.

## Counterparty = the name only

- Drop the masked account in front (`3237XXXXXX`) — it is not a name.
- A company name ends at `SDN BHD` (also `SDN. BHD.`, `SDN.`, truncated `SDN`, `SD`, `BERHAD`, `BHD`, `PLT`, `ENTERPRISE`, `TRADING`). What follows is the customer's reference → Description.
- People have no suffix to stop on. Build a list of names already seen in this customer's statements and split by **longest match**. Add new names as you meet them.
- Keep the bank's uppercase, matching the template.
- Bank codes glued to the end of a name (`... MBB`, `... CIMB`) are not part of the name.

## Rows nobody typed anything into

Write a short plain-English Description and leave Counterparty empty:

| Bank text | Description |
|---|---|
| SC / SERVICE CHARGE | Service charge |
| GST DR / SST DR | GST on service charge / SST on service charge |
| HANDLING CHRG … AUDIT CONFIRMATION | Handling charge - audit confirmation |
| DEP-LOC CHEQ 123456 | Cheque deposit (cheque number → Cheque / serial no) |
| CHQ PROCESS FEE DR | Cheque processing fee |
| GIRO PYMT … JOMPAY … | JomPAY payment (biller name → Counterparty) |
| INTEREST / PROFIT PAID | Interest credited |
| STAMP DUTY | Stamp duty |
| RETURNED CHEQUE / CHQ RTN | Returned cheque (number → Cheque / serial no) |

When unsure whether a word was typed by the customer or generated by the bank, keep it and list it as a judgement call.
